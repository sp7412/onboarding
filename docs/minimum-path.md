# Minimum Path: 10 Hours to Day One

**Facts as of: October 6, 2026 · Last reviewed: October 6, 2026**

If you have less than three weeks, do not try to finish the entire library. Spend about
10 hours learning the system boundary, exercising it, and preparing questions.

| Step | Time | Deliverable |
|---|---:|---|
| Pantheon brief + hypothesis map | 45 min | Write down 12 questions you want answered |
| Voice-agent architecture | 45 min | Draw one call from audio to authoritative state |
| Lab 02 — tools/guardrails | 60 min | Explain where the model stops |
| Lab 07 — tracing/evals | 60 min | Identify the denominator and failure taxonomy |
| Lab 13 — Mini-Max | 120 min | Run 20 calls and inspect the sensitivity table |
| Lab 14 — earning autonomy | 120 min | Defend one promotion/demotion policy |
| Business metrics + value calculator | 45 min | Compute a contractor-facing value case |
| Field exercise | 60 min | Capture domain observations using the template |
| Manager alignment | 45 min | Prepare first-1:1 questions and a 30/60/90 draft |
| **Total** | **10 hours** | A system-level mental model, not a feature checklist |

## The output you should carry into week 1

You should be able to:

1. trace one call into structured facts;
2. explain which facts are authoritative and which are proposals;
3. explain how booking, lead scoring, and dispatch can interact;
4. describe why an autonomy promotion needs statistical evidence;
5. state the business cost of false booking versus missed opportunity;
6. walk in with a dozen public-grounded hypotheses/questions.

If you have more time, do exercises 3 and 4 of the [senior engineer judgment track](../senior-engineer/README.md)
(latency budget, evaluation denominators), then the [full lab sequence](../labs/README.md),
the reading guide and the 30/60/90 checklist.
