# 09 - Competitive Landscape

**Estimated reading time:** 3 minutes

## Five Takeaways

1. A responsible comparison needs individually verified current competitor sources.
2. No competitor ranking is asserted in this phase.
3. Comparison dimensions are more durable than a vendor list.
4. Public positioning does not reveal win/loss, pricing, adoption, or implementation depth.
5. This chapter remains a research gap rather than fabricated completeness.

## Comparison Dimensions

Future research should compare verified public offerings across workflow integration,
transaction authority, scheduling and dispatch depth, telephony, human transfer,
configuration, evaluation, observability, deployment model, and customer evidence. Each
row needs a URL checked on the publication date and must distinguish product positioning
from independent corroboration.

The current source set is sufficient to describe ServiceTitan's public positioning, but
not to name a complete or fair competitor set. The plan specifically warns against
constructing URLs from memory or treating unlike answering services, contact-center
platforms, field-service systems, and voice startups as equivalent. This chapter therefore
contains no unsupported vendor claim.
